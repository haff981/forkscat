# 🐱 Forks Cat — $FORKSCAT

Fortune favors the fork.

Forks Cat is a fork-loving cat meme coin. Simple as that: cats sell,
forks fork, and a cat with a fork brings luck to everyone who holds it.

## The coin

- **Name:** Forks Cat
- **Ticker:** $FORKSCAT
- **Chain:** Solana
- **Launch:** [forks.wiki](https://forks.wiki) — one coin per repository,
  launched on this repo via pump.fun

## How it works

This repository is the home of the $FORKSCAT coin. Its creator fees are split
on-chain, for good, between the people behind the code:

- **50%** to the launcher
- **30%** to the repository
- **20%** to forks

The split is locked at launch and can never be changed.
